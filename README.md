# Real-Time Collaborative Coding Platform

**Author:** Rishabh Kumar

## Overview
An enterprise-grade collaborative code editor designed to handle real-time distributed state. This MVP focuses on the core WebSocket synchronization layer and frontend editor integration, built for a 3-day sprint.

## Tech Stack
*   **Backend:** Java / Spring Boot, Spring Security
*   **Frontend:** React, TypeScript, Monaco Editor
*   **Database:** PostgreSQL
*   **Real-time:** Spring WebSockets (STOMP)
